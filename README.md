# iclip-ultraplex-multiqc
### iCLIP Demultiplexing with Ultraplex and MultiQC

This repository provides a small but practical workflow to:

1. **Demultiplex iCLIP / iiCLIP libraries** using [Ultraplex](https://github.com/goodwright/ultraplex) and internal barcodes.
2. **Parse Ultraplex log files** to extract summary statistics (reads processed, % trimmed, % assigned, etc.).
3. **Generate a MultiQC report** that includes:
   - A custom table summarizing all Ultraplex metrics.
   - A barplot showing the percentage of correctly assigned reads per demultiplexed pool.

This is particularly useful for iCLIP libraries using RT primers with internal barcodes in the format  
`NNNN,XXXXX_0,W WW` (UMI + barcode + random bases).

---

## Requirements

- Python ≥ 3.8  
- MultiQC ≥ 1.10  
- matplotlib  
- Ultraplex installed (via conda or pip)

---

## 1. Project Inputs

Before running anything, ensure your project directory contains:

### ✅ FASTQ files (after Illumina demultiplexing)

Example:

```
file1.fastq.gz
file2.fastq.gz
...
fileN.fastq.gz
```

### ✅ Barcode files (Ultraplex format)

One file per pool (**barcodes can be reused across different samples ⚠️**).

Each file contains lines like:

```
NNNNTCCACNNN:condition1_rep1,
NNNNTTTAANNN:condition1_rep2,
```

Where:

- `NNNN` = UMI (4nt)  
- `TCCAC` / `TTTAA` = internal RT barcode  
- `NNN` = random bases  
- Text after `:` = output sample name used for Ultraplex FASTQs  

An example barcode file is provided under the `examples/` folder.

## 2. Directory Structure (before running)

Your project root directory should resemble:

```
project/
├── file1.fastq.gz
├── file2.fastq.gz
├── ...
├── barcodes_pcr1.csv
├── barcodes_pcr2.csv

│   └── run_ultraplex_example.sh
└── config/
    └── multiqc_config.yaml
```

➡️ **All commands must be run from this root directory.**

## 3. Demultiplexing with Ultraplex

Use the script `scripts/run_ultraplex_example.sh` as a template.

Example:

```bash
#!/usr/bin/env bash
set -euo pipefail
BASE=/path/to/project
cd "$BASE"

# Create output folders
for i in {1..n}; do
    mkdir -p "demux_pcr${i}"
done

# Run Ultraplex for pool 1
ultraplex -i file1.fastq.gz -b barcodes_pcr1.csv -o demux_pcr1/ultraplex_demux_pcr1 -t 8 --fiveprimemismatches 0

# Repeat for pools 2..n
```

Each run produces:

- Demultiplexed FASTQ files per sample  
- A `.log` file under `demux_pcrX/`

**If log files are missing, the next steps will not work.**

---

## 4. Parsing Logs and Generating Summary

Run:

```bash
python scripts/parse_ultraplex_logs.py
```

This script:

- Searches all `demux_pcr*/**/*.log` files  
- Extracts the last 5 summary lines from each log  
- Generates:

```
ultraplex_summary.tsv
```

- Creates a barplot:

```
ultraplex_assigned_barplot_mqc.png
```

The `_mqc` suffix ensures MultiQC automatically embeds the figure.

---

## 5. MultiQC Integration

Before running MultiQC, ensure these files exist in the project directory:

- `ultraplex_summary.tsv` (generated by the script)  
- `ultraplex_assigned_barplot_mqc.png` (barplot for MultiQC)

If any file is missing, the **Ultraplex summary** section will be empty.

Run MultiQC from the project root directory:

```bash
multiqc . -o multiqc_ultraplex
```

This produces:

```
multiqc_ultraplex/multiqc_report.html
```

The report includes:

- A summary table for all Ultraplex pools  
- A barplot showing **% reads assigned** per pool
